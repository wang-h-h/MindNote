## 已验证的数据升级行为

- schema 1／2 旧库升级前，通过 SQLite `VACUUM INTO` 创建一致备份，安全副本保留旧格式与完整 payload。
- 当前 payload 与 `user_version=3` 在同一事务写入；重新打开已升级数据库不会再次迁移。
- schema 2→3 仅补充默认 `gridColumns=3`，节点 ID、关系、备注、进度、准确完成时间和窗口位置保持不变。
- schema 1 同时完成已有的主题、时间字段、显式计划标记与独立进度迁移。
- schema 1／2／3 备份均可恢复；导入旧备份不改写源文件，恢复前自动保存当前数据的安全副本。
- 宫格列数只接受 1／2／3／4；选择保存到数据库，重启后恢复。

# MindNote 2.0 · 思维便签

桌面便签、三周计划和项目导图共用同一份事项，在两个窗口中都可以看到最新进度。

Capture tasks in a desktop sticky note, plan across three weeks, and follow each task back to its mind map. Everything is saved locally.

**Mac 系统要求**为 macOS 13 或更高版本。两个安装包均使用本地签名（ad hoc），未经 Apple Developer ID 签名和公证，首次打开时可能会被系统拦截。界面为简体中文。

Both Mac builds require macOS 13 or later. They use ad hoc signing and have not been notarized by Apple. Gatekeeper may block the first launch. The interface is in Simplified Chinese. [Apple 首次打开说明](https://support.apple.com/zh-cn/102445) · [Apple’s guide to opening apps](https://support.apple.com/en-us/102445)

**自定义背景**　在「外观设置 → 背景图片」中选择风景照片、GIF 或动态 WebP，便签和主窗口会同步更新。

Choose a still image or animation in Appearance to change the background in both windows.

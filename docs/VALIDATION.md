## 置顶修复证据

旧 V1.2 包在主动清除原生置顶标志的故障注入下，重新显示／关闭到托盘后恢复／最小化后唤回／原生还原／resume／unlock-screen／显示变化七条路径均没有恢复保存的置顶选择。V2.0 在相同注入后均恢复；系统事件不会抢焦点、不会重新打开已隐藏的便签；取消置顶同样保持。基线见 [pinning-v2-baseline.json](verification/v2.0.0/pinning-v2-baseline.json)。

唤醒、解锁和显示变化通过事件注入检查，不是实际锁屏、休眠或拔插显示器。该结果证明恢复逻辑缺口得到修复，不证明已查明其他电脑触发置顶失效的具体原因。

## 覆盖边界

置顶修复针对可复现的生命周期恢复缺口；本机验证不能代替用户反馈电脑的实机测试。Windows 的安全桌面和其他同为置顶的特殊窗口不在普通应用遮挡保证范围内。

不执行安装器，不改写用户桌面快捷方式或卸载注册信息。安装程序保留安装目录选择和 data 目录，作者／安装信息发布者为 whh；没有配置代码签名。多电脑、不同显卡与 Windows 版本仍需额外实机覆盖。

# 思维便签 MindNote 2.0 使用说明

MindNote 用计划视图安排事情，用思维导图梳理关系。两者使用同一份本地内容，不需要注册账号。

## 1. 打开软件

启动后只显示桌面便签，默认选中「今日」。便签可切换「收集箱、今日、本周、本月」，不显示「全部事项」入口。

点击便签右上角的箭头打开完整窗口。主窗口提供今日概览、周计划、月历、全部事项，以及左侧的项目导图。计划页面直接展示待办；需要理解某项的层级关系时，点击它的定位导图按钮。

主窗口右上角可最小化、最大化／还原和关闭到托盘。关闭窗口不会完全退出；托盘右键菜单中的「退出思维便签」会退出程序。单击托盘图标显示便签，双击可打开主窗口。

主窗口与便签均为 20px 平滑圆角，主窗口最大化后填满可用工作区。拖动主窗口任一边缘或角可调整尺寸。便签拖到屏幕工作区的任一边缘附近会吸附，左右上下均支持。

桌面便签标题栏最右侧的 × 用于关闭便签到托盘，不退出软件；点击托盘图标或托盘菜单「显示桌面便签」即可重新打开。重新显示、还原或电脑唤醒时，会重新应用保存的置顶选择。

## 2. 新增与安排日期

点击「新增待办」或便签底部的输入入口；非编辑状态下也可按 `Ctrl + N`。

1. 输入事项名称并确认所属项目；直接记录的零散事项默认归入「草稿箱」。
2. 日期默认今天。点击较大的「今天／本周／本月」按钮可快速填写范围，本周从周一开始。
3. 开始和结束相同表示单日，不同表示一个时间段，首尾日期都包含在内。
4. 点击「暂不安排」可先放入收集箱，起止日期框保留显示并清空。日期选择只使用年月日，没有时分。

有可继承任务父项时，同一行还会显示「跟随父项」。选择后，两个日期框显示父项当前生效的日期；父项日期变更时会一起更新。直接编辑日期框或点击今天／本周／本月，会改为这个事项自己的指定日期。

在独立项目中创建事项时，可通过「加入我的计划」决定是否立即安排。该选择只影响新建的这一个事项，不会因为父节点在计划中就自动把整条分支加入计划。

已安排事项可以在详情中调整日期。周计划支持将事项拖到另一周（移动到该周周一），月历支持拖到另一日期，时间段会保持原来的跨度。调整错误可撤销。

## 3. 查看计划与更新进度

| 入口     | 用途                                         |
| -------- | -------------------------------------------- |
| 收集箱   | 已记录但暂未安排日期的事项                   |
| 今日概览 | 选择日期查看当天安排，并保留未完成的逾期事项 |
| 周计划   | 上周、本周、下周三个便签；周一为起点         |
| 月历     | 点击日期查看当天安排，添加或移动事项         |
| 全部事项 | 便签宫格，可筛选全部、待推进、已归档         |

每个计划项都使用两行展示：第一行是名称、所属项目标签和详情／导图定位按钮；第二行左侧为日期，右侧为进度条和百分比。日期省略重复年份，跨年范围会标明两端年份；将鼠标停在日期上可查看完整年月日。未完成事项在到期当天及逾期后，日期显示为红色加粗，不额外显示「今日到期」文字。

同一项目的事项归为一组，点击组标题可折叠或展开。首次进入时，未完成事项优先并按较早到期排序，完成项按最近完成时间倒序。当当前窗口能完整显示全部可见事项时，完成后保留原位置；需要滚动才能看全时，完成事项才下沉。改变窗口大小本身不会让事项反复跳动。折叠仅收起当前视图，不会删除事项或改变计划关联。计划仍只显示明确加入的节点，不补上父节点，也不自动列出其子节点。

拖动第二行的进度条更新进度，每次吸附到 10% 的刻度，最右侧同步显示百分比。滑块到 100% 时表示完成，名称保持原字号、字色和字重，仅加明显黄色划线；调回较低进度可重新打开事项。界面不另设数字进度输入框或完成按钮。

完成事项不会因为进度达到 100% 而消失，除非开启外观设置中的「隐藏划线事项」。有日期的完成事项会显示在原计划日期范围内，也显示在实际完成日期所属的日／周／月。例如上周逾期的事项今天完成，今日及本周仍能查到它，原计划日期也保留记录。无日期事项仍留在收集箱。

周计划固定展示上周、本周和下周，各周内按项目分组；旧的未完成逾期事项延续显示在本周。今日概览和周计划不再显示「回到今天」按钮，今日顶部的日期条仍可切换日期。「全部事项」主动选择「已归档」时会显示归档记录，不改变全局的隐藏设置。

**各事项的进度独立。** 即使一个计划项在导图中有子节点，也可以单独拖动它的进度，父子之间不会自动完成或互相改写。颜色结合到期距离和当前进度提示关注程度；完成项使用完成样式。

「全部事项」按项目展示便签宫格。右上角的 1／2／3／4 可切换列数，默认 3 列；选择会保存，并同步到同时打开的窗口。较窄窗口中可水平滚动查看所选列数。卡片顶部保留两行，下方完整展示已填写的进展、问题和备注；空字段不显示。日期不会自动生成下一轮任务，软件不弹系统提醒。

## 4. 记录进展和备注

点击事项标题打开详情，可以修改名称、日期，以及「进展说明」「问题与阻碍」「其他备注」。已完成事项仍可填写复盘与补充内容。

导图右侧详情与画布上下对齐，日期区域靠左，右侧并排显示「取消计划」。备注默认显示两行，输入较长内容时会自动长高。

停止输入约 0.65 秒后自动保存，移开焦点立即保存。中文输入法候选组合期间会等待输入完成。若保存失败，原输入和重试入口会保留；切换事项再回来仍可恢复本次运行中的未保存草稿。

未保存草稿仅保存在当前运行的内存中，退出前应处理保存失败提示；这些草稿不会跨重启保留。已成功保存的内容不受此限制。

## 5. 项目与草稿箱

左侧「思维空间」用于创建和打开导图。普通项目按「项目→大任务→子任务」组织，可继续添加更深层级。

「草稿箱」是直接新增待办的系统归属，不能删除或重命名。画布隐藏它的总根节点，因此可以看到多个独立的顶层事项，不需要把所有内容挂在一个显眼的大标题下。隐藏仅影响显示，不会删除节点或断开关联。

普通项目可以只用于梳理想法。选中某个节点，在详情中选择「加入计划」，或右键选择「关联计划」，再填写日期。**只有选中的节点加入计划**；父节点、兄弟节点、子节点都保持原来的安排。

关联后仍在原项目中编辑同一个节点，改名、备注和进度会同步显示。详情中的「取消计划」可将它移出计划视图，同时保留导图节点与已有记录。

## 6. 导图操作

- 右键节点：添加子项、添加同级、编辑名称、关联／调整计划、删除节点。
- 右键空白：新建分支、适应画布。
- 左键拖动空白区域平移；滚轮缩放；拖动节点调整层级和位置。
- 双击节点或按 `F2` 编辑名称。按 `Enter` 提交文字，`Escape` 取消本次文字修改；中文候选确认不会直接变成新增命令。
- 底部「适应画布」显示当前导图；「展开层级」提供主干一层、展开两层、展开全部，方便在大纲与细节之间切换。

切入项目时会适应画布；之后折叠、展开、编辑等操作保持当前平移和缩放，不自动重新居中。需要重新总览时点击「适应画布」。导图左下角保留操作提示。

| 操作                       | 快捷键                                       |
| -------------------------- | -------------------------------------------- |
| 添加子项                   | `Tab`                                        |
| 添加后一个同级项           | `Enter`；项目根没有同级时创建子项            |
| 编辑名称                   | `F2` 或双击                                  |
| 删除节点                   | `Delete` 或 `Backspace`                      |
| 选择父节点／第一个子节点   | 左／右方向键                                 |
| 选择上一个／下一个同级节点 | 上／下方向键                                 |
| 放大／缩小                 | `Ctrl + +`／`Ctrl + -`                       |
| 恢复 100% 比例             | `Ctrl + 0`                                   |
| 撤销／重做                 | `Ctrl + Z`／`Ctrl + Shift + Z` 或 `Ctrl + Y` |

删除包含后代的节点会提示影响范围，并同时删除其关联待办。删除独立项目会删除整个项目。误操作可撤销；系统草稿箱不能整张删除。

## 7. 外观与桌面便签

整体采用雾灰玻璃界面，以深蓝和暖黄点缀，应用图标使用用户提供的 M N 便签图像。主窗口顶部可快速切换浅色／深色；「外观设置」右侧将背景图片放在效果预览上方，左右设置行对齐。导图使用已确认的 A「雾蓝同色系」，所有分支采用统一色系与不同明暗层级。

| 设置         | 范围与默认值         |
| ------------ | -------------------- |
| 主题         | 浅色／深色，默认浅色 |
| 背景不透明度 | 35%–100%，默认 82%   |
| 背景模糊     | 0–36，默认 18        |
| 界面字号     | 12–18，默认 14       |
| 减少动效     | 默认关闭             |
| 开机启动     | 默认关闭             |

桌面便签可拖动标题区域移动、拖动右下角调整大小、收起为标题条或切换置顶。软件记住窗口位置与尺寸；文字不会随背景不透明度一起变淡。「背景模糊」直接柔化添加的图片背景，拖动时即刻预览；不会模糊 Windows 桌面壁纸。没有添加背景时，窗口中的变化可能不明显。

便签的外观设置按钮在标题栏、置顶按钮左侧。设置页顶部关闭按钮保持可见。

点击「添加背景」选择 PNG、JPEG、GIF 或 WebP（最大 20 MB）。背景同步应用到完整窗口和便签，支持 GIF／WebP 动画；开启「减少动效」后显示静态首帧。点击「移除」恢复原背景。原图存入数据库，因此删除或移动原图片文件不会影响背景。

## 8. 搜索、备份与升级

按 `Ctrl + K` 或点击顶部搜索入口查找事项与想法。搜索结果可打开内容或定位原导图。

在「外观设置」的数据区域点击「备份数据」，保存 `.sqlite` 文件。恢复时选择此前的 `.sqlite`、`.mindnote` 或 `.db` 备份；恢复会替换当前导图、计划和设置，之前的内容会自动备份到数据目录的 `backups` 子目录。

V1.2 数据格式为 schema 4，兼容恢复 schema 1／2／3／4 备份。首次升级旧库前先创建安全备份，保留节点、进度、时间、备注、主题和窗口位置；旧格式没有背景时保持原外观。背景原始图片也在数据库中，备份恢复不依赖外部图片路径。

安装时可选择位置，默认 `%LOCALAPPDATA%/Programs/MindNote`。应用数据在所选目录下的 `data` 文件夹，点击「打开数据文件夹」可直接核对。请选择当前用户可写的目录；更新前从托盘退出旧版。首次启动会安全迁入检测到的旧版数据库，原数据库保留不动，迁移副本保存在新目录的 `data/backups`。安装器作者／发布者信息为 `whh`，桌面名称为 `MindNote`；未签名版本仍可能显示 Windows 的未知发布者提示。

卸载只删除程序，保留 data。若移动整套程序，请先退出 MindNote，再将应用文件夹连同 data 一起移动；仅复制 EXE 无法完整迁移应用。

在新电脑上安装 MindNote 后恢复备份即可迁移，两台电脑没有自动同步。点击数据区域的文件夹按钮可查看数据目录。备份请使用应用提供的功能，不要在运行时只复制单个数据库文件。

## 9. 常见情况

- **导图子项没有出现在计划里：** 这是独立关联规则；选中需要执行的具体节点并加入计划。
- **子项已经完成，但父项没完成：** 进度独立，父项需要自己更新。
- **新增事项没有出现在今日：** 检查是否选择了「暂不安排」，或日期属于其他时间。
- **启动后没有主窗口：** 默认只打开便签；点击右上角箭头或双击托盘图标。
- **草稿箱看不到大根节点：** 总根节点被隐藏，顶层事项与其后代仍完整保存。
- **恢复后还能撤销到恢复前吗：** 恢复会清空本次会话历史；恢复前的数据保存在自动安全备份中。
- **重新启动后不能继续撤销：** 撤销历史仅保留在本次运行中，已保存内容仍会保留。

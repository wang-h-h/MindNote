# MindNote 2.0.0

- 修复逾期事项拖动进度到 100% 后从今日／本周消失的问题；完成项按原计划日期与实际完成日期保留，显式隐藏时才过滤。
- 完成名称保留原字号、字色与字重，仅加明显的黄色划线；计划列表、宫格、月历、详情和思维导图保持一致。
- 周计划改为上周、本周、下周三个周便签，按项目分组；今日概览和周计划移除「回到今天」。
- 桌面便签标题栏最右侧增加关闭按钮，关闭到托盘，保留数据和其他窗口。
- 加强 Windows 置顶恢复：重新显示、最小化还原、系统唤醒／解锁和显示器变化后重新应用保存的选择，取消置顶同样生效。
- 全部事项明确选择「已归档」时可查看已完成记录，不改写全局隐藏设置。

安装目录、数据格式、图标、雾蓝导图及其余功能沿用 V1.2。升级使用现有 data，不清空待办。作者／发布者为 whh，桌面快捷方式名称为 MindNote。

# MindNote 1.2.0 版本说明

更新日期：2026-11-15。

## 窗口与界面

- 完整窗口与桌面便签统一为抗锯齿 20px 圆角；最大化填满工作区，主窗口支持八方向调整大小。
- 便签新增左右吸附，与上下组成四边吸附；外观设置按钮移至标题栏置顶按钮左侧。
- 主窗口品牌下增加「思维便签」；「我的计划」「思维空间」字号与导航项一致，删除「· 项目」。
- 全部事项宫格在两行顶部下完整展示进展、问题与备注，空字段不占位；完成名称采用加粗暖黄划线。
- 当前列表完整可见时，完成事项保留位置；出现滚动溢出时才下沉。窗口变大变小本身不触发反复排序。

## 导图

- 修正反复从主干一级展开全部后的连线位置，以及双击编辑时节点缩小、内容重叠的问题；节点草稿尺寸和连线同步。
- 经用户确认采用 A「雾蓝同色系」，分支统一用色、层级通过明暗区分，浅色与深色均配套。
- 计划日期缩短，「取消计划」与日期并排，按钮样式与「加入计划」统一。
- 左下操作提示与右下工具条向画布底部靠拢，保留必要提示。

## 背景与数据

- 外观设置增加静态／动态背景：PNG、JPEG、GIF、WebP，最大 20 MB。完整窗口与便签同步使用，减少动效时显示首帧。
- 背景模糊直接作用于添加的图片，拖动即时预览；不会模糊系统桌面壁纸。
- 背景放在右侧效果预览上方；数据区只占左半列，三个数据操作统一为按钮，两列各行对齐。
- schema 4 将背景原图存入 SQLite，备份与恢复包含图片；旧库迁移前自动备份。

## 安装

- 改为可选择安装路径的 NSIS 安装程序，默认文件夹名 `MindNote`。
- 作者、公司及安装注册信息的发布者为 `whh`；桌面快捷方式名仅为 `MindNote`。
- 数据位于 `<安装目录>/data`，首次启动安全迁入旧库，保留旧库与备份；卸载保留 data。
- 未配置代码签名，因此元数据中的发布者名称不等同于 Windows 已验证发布者。

本轮测试结果、实际交付文件与覆盖边界见 [验证记录](VALIDATION.md)。V1.0／V1.1 交付保留。

# MindNote 1.1.0 版本说明

更新日期：2026-11-15。

## 待办与计划

- 每项统一为两行：名称、项目标签、导图定位和详情展开按钮；日期、进度条和右侧百分比。去掉重复到期文字，以红色加粗日期标出当天到期及逾期的未完成事项。
- 同项目按可折叠分组展示。组内未完成优先、完成项按完成时间倒序；项目组按最高优先级事项排列。计划成员仍是明确加入的单个节点，不自动纳入父子节点。
- 全部事项仍为便签宫格，卡片去掉备注摘要和额外时间底栏。新增 1／2／3／4 列选择，默认 3 列，跨窗口同步并持久保存。
- 保留独立进度与 10% 步长；没有真实修改时不写入，连续拖动按顺序提交，并以最新版本对齐跨窗口更新。
- 日期模式改为同排「暂不安排／跟随父项」按钮，两个日期输入始终显示；跟随时展示父项有效日期。日／周／月快捷入口统一图标。

## 窗口、导图与外观

- 修正透明便签圆角外的方角区域；主窗口还原时保留单层圆角，最大化后填满工作区，底部工作区信息完整显示。
- 便签设置页去掉外围灰边，固定标题和关闭入口；设置页将效果预览放在右上，左右设置行对齐。
- 导图日期左对齐，详情与画布上下对齐，备注由两行起自动长高。
- 提高导图对比度，折叠和编辑保持当前视角；切入项目及手动「适应画布」时才重新适配。
- 原样采用用户提供的新版 M N 图标，移除非必要标语、装饰卡片和重复说明；保留导图操作提示。

## 数据升级

数据库升级为 **schema 3**，增加 `gridColumns`（1–4，默认 3）。打开 schema 1／2 时先保存一致的旧库安全备份，再事务升级；源库安全副本保留原始格式和内容。

从 V1.0（schema 2）升级时，节点 ID、层级、进度、完成时间、备注、其他设置与窗口位置不变。支持恢复 schema 1／2／3 备份，所选源备份不被修改；恢复前仍自动备份当前数据。

## 验证状态

当前 **5 个测试文件、70 项自动化测试与整项目 TypeScript 检查通过**。新增项目分组排序、双行与百分比展示、日期简写、宫格设置校验与重启持久化，以及 schema 2→3 自动备份迁移和旧备份导入回归。

另有 **17 组真实界面、10 组组件和 16 组导图回归通过**。Windows x64 安装包已生成；**打包版 17 组界面、10 组原生桌面和 3 项真实桌面圆角检查全部通过**，包含三种 DPI、SQLite 读写、备份恢复及重启保存。完整结果、安装包哈希与覆盖边界见 [验证记录](VALIDATION.md)。安装器未签名，未执行安装；V1.0 安装包及源码保留。

# MindNote 1.0.0 版本说明（历史）

更新日期：2026-11-15。

V1.0 将工作重心放在待办计划上。导图继续保留完整层级，用于整理项目；计划通过明确选中的节点与导图关联。

## 界面与工作方式

- 启动只显示桌面便签，默认今日；完整窗口按需打开。便签保留收集箱、今日、本周、本月四个入口。
- 主窗口以今日概览、周计划、月历、全部事项为主，计划页不再提供导图模式切换；事项上的链接定位原导图。
- 全部事项使用便签宫格，未完成优先，完成项按完成时间倒序排列。
- 采用用户提供的 `UI Reference` 视觉方向与 PNG 图标，主题收敛为浅色／深色，增加快捷主题切换和 `Ctrl + K` 搜索。
- 新增默认今天的日期选择、大尺寸今天／本周／本月快捷按钮，以及复选式「暂不安排」。日历日期不显示时分。
- 外观设置增加双主题预览、背景模糊、字号和减少动效；主窗口支持最大化／还原。

## 计划与进度

- 加入计划只作用于选中的一个节点，不自动包含父节点或子节点；计划项显示所属项目。
- 所有计划项独立更新进度，包括导图内有子节点的父事项。
- 使用以 10% 吸附的滑块，移除数字进度输入和单独完成按钮；滑到 100% 自动完成，滑回即可重新打开。
- 进度条颜色结合到期距离和进度提示关注程度；完成后仍可修改备注。

## 导图调整

- 系统导图改名为「草稿箱」，隐藏总根节点，支持多个顶层事项；普通项目保留项目→大任务→子任务结构。
- 右键提供添加子项／同级、改名、关联计划、删除；空白左键拖动平移，滚轮缩放，保留「适应画布」。
- 修正节点删除、切换导图后引用失效与子项显示问题，以及编辑器位置的处理。
- 新增主干一层／展开两层／展开全部。此项是本轮确认的额外导图优化；未加入导图导出或专注功能。

## 数据升级

数据库升级为 schema 2。升级前先创建完整旧库安全备份，再通过事务写入新格式。支持恢复 schema 1 与 schema 2 备份，源备份不被修改。

保留旧节点 ID、层级、文本、日期和备注；旧父项的可见汇总进度固化为独立进度。新增时间字段用于完成排序；旧版缺失的时间以所属导图创建时间补齐。四套旧主题迁移为浅色。

## 验证状态

62 项自动化测试、整项目 TypeScript 检查与生产构建通过。Windows x64 安装包已生成；打包版 13 组界面流程、10 组原生桌面检查与资源校验通过，包含三种 DPI 的重复显示和重启验证。详见 [V1.0 历史验证记录](VALIDATION-1.0.md)。

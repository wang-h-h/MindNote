## 已验证的迁移行为

- 旧库迁移前通过 SQLite `VACUUM INTO` 创建一致备份，备份仍保留 schema 1 和原始内容。
- payload 与 `user_version=2` 同一事务提交；无效旧库不会被部分升级。
- 保留节点 ID、文本、层级、日期与备注，旧父项实际显示进度在升级后保持。
- 四套旧主题转为浅色，新增外观字段补默认值，缺失时间稳定回填。
- 旧备份恢复到当前数据库时先备份现有数据，源备份保持不变。
- 完成／重新打开维护 `completedAt`，撤销和重做恢复准确的历史时间值。
